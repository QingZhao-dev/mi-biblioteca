
# Mi biblioteca

## Descripción
Aplicación de consola desarrollada en Java para gestionar una colección de libros mediante un menú interactivo.

## Funcionalidades
- Añadir libros a la colección.
- Consultar la lista de libros.
- Modificar el estado de los libros.
- Navegar por las opciones mediante un menú de consola.

## Tecnologías utilizadas
- **Java:** desarrollo de la lógica de la aplicación.
- **ArrayList:** almacenamiento y gestión de la colección de libros.
- **Scanner:** lectura de los datos introducidos por el usuario.
- **Condicionales y bucles:** control del menú y sus opciones.

## Cómo ejecutar el proyecto
1. Clona o descarga este repositorio.
2. Abre el proyecto en un entorno de desarrollo compatible con Java.
3. Ejecuta la clase principal que contiene el método `main`.

## Posibles mejoras
- Buscar libros por título.
- Modificar la información de los libros.
- Incorporar una base de datos.
